# Code of conduct

## The standard

Be straightforward and be kind. Those are compatible.

This project reviews work that sits close to people's money, so the technical bar
is high and criticism is expected. Direct criticism of an idea, a design, or a
line of code is welcome and is the point. Criticism of a person is not.

## Expected behaviour

- Argue about the bytes. Bring the input, the expected value, and the actual value.
- Assume the other person read the specification and reached a different reading.
  Say which sentence, and why.
- Accept a correction without ceremony, and give one the same way.
- Recognize that people contribute across languages, time zones, and experience
  levels. A question that seems obvious to you was not obvious to them.

## Unacceptable behaviour

- Personal attacks, harassment, or sustained disruption.
- Publishing someone's private information.
- Sexualized language or imagery, and unwelcome attention of any kind.
- Dismissing a security or safety concern to protect a release, a schedule, or a
  narrative.

## Scope

This applies in issues, pull requests, discussions, commit messages, and any space
where you are representing the project.

## Enforcement

Report a problem to the repository owner through the Bitcoin Universe organization
profile. Reports are handled privately. The maintainer may warn, remove content,
or block an account, and will not discuss a reporter's identity publicly.

If a report concerns the maintainer, say so in the report. It will still be read.
