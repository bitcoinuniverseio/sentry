# Sentry

> **Archived on 26 August 2026.** This repository is frozen. It receives no
> changes, no fixes, and no support. It is kept so the record of the Sentry
> protocol and its URLs stay resolvable.

## What this was

Sentry was a Bitcoin protocol developed inside Bitcoin Universe. It did not
reach a public release, and the work was retired rather than shipped.

## Why it is empty

The repository contents were removed in commit
[`7a8c9b5`](https://github.com/bitcoinuniverseio/sentry/commit/7a8c9b5e42b41d69431616275fe409339828e9ef)
before the repository was archived. The last commit that still carried the
protocol material is
[`4c48ff2`](https://github.com/bitcoinuniverseio/sentry/commit/4c48ff2f0d572ecbee79067eb2239a455c61f085)
(10 August 2026), and it remains reachable through the Git history of this
repository.

## Is it safe to use

No. Nothing here was released, nothing is maintained, and nothing was audited
for production use. Do not build against material recovered from this history
and do not treat it as a specification.

## What replaces it

Nothing directly. Sentry was retired without a successor. If you arrived here
looking for a Bitcoin protocol Universe actually ships, the
[Protocol Atlas](https://docs.bitcoinuniverse.io/protocols/) lists every
protocol that is documented and where its specification lives.
